# KAIROS — Environment Variables Checklist

This file lists all environment variables used by the KAIROS project. Copy `.env.example` to `.env.local` and fill in all values.

---

## Supabase (Authentication & Database)

| Variable | Description | Required? | Source |
|----------|-------------|-----------|--------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL (e.g., `https://project.supabase.co`) | Yes | Supabase Dashboard → Settings → API |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anonymous/public JWT key | Yes | Supabase Dashboard → Settings → API |
| `SUPABASE_SERVICE_ROLE_KEY` | Server-side service role key (full access) | Yes | Supabase Dashboard → Settings → API |
| `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN` | PostHog analytics project token | Optional | PostHog dashboard |
| `NEXT_PUBLIC_POSTHOG_HOST` | PostHog instance host (e.g., `https://us.i.posthog.com`) | Optional | PostHog dashboard |

---

## Freqtrade (Trading Bot Engine)

| Variable | Description | Required? | Default | Notes |
|----------|-------------|-----------|---------|-------|
| `FREQTRADE_URL` | Freqtrade REST API URL | Yes | `http://localhost:8080` | If running Docker container |
| `FREQTRADE_USER` | Freqtrade API username | Yes | `freqtrader` | Configured in `config.json` |
| `FREQTRADE_PASS` | Freqtrade API password | Yes | `change_me` | Configured in `config.json` |

---

## Google Gemini AI (Vibe-Trading Strategy Lab)

| Variable | Description | Required? | Notes |
|----------|-------------|-----------|-------|
| `GOOGLE_API_KEY` | Google Gemini API key | Yes | Used by `/api/vibe-trading/*` endpoints |

---

## Analytics (Optional)

| Variable | Description | Required? |
|----------|-------------|-----------|
| `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN` | PostHog project token for analytics | Optional |
| `NEXT_PUBLIC_POSTHOG_HOST` | PostHog host URL | Optional |

## Example `.env.local`

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here

# PostHog (optional analytics)
NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN=your-posthog-token
NEXT_PUBLIC_POSTHOG_HOST=https://us.i.posthog.com

# Freqtrade
FREQTRADE_URL=http://localhost:8080
FREQTRADE_USER=freqtrader
FREQTRADE_PASS=change_me

# Google Gemini
GOOGLE_API_KEY=your-gemini-api-key-here
```

---

## Security Notes

- **Never commit `.env.local`** — it's gitignored
- `NEXT_PUBLIC_` prefix = exposed to browser (safe for non-secret values only)
- `SUPABASE_SERVICE_ROLE_KEY` = server-side only, keep secret
- `FREQTRADE_PASS` = never expose to frontend; used in API proxy routes only
- `GOOGLE_API_KEY` = embeds in client code via `NEXT_PUBLIC_`, rotate regularly
